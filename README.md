# Festivos LATAM: privacidad y soporte

Sitio público de política de privacidad, soporte y `app-ads.txt` para Festivos LATAM.

- Privacidad: https://steveazul87.github.io/festivos-latam-privacy/
- Soporte: https://steveazul87.github.io/festivos-latam-privacy/support.html
- AdMob: https://steveazul87.github.io/app-ads.txt

AdMob obtiene `app-ads.txt` desde la raíz del dominio indicado como sitio web
del desarrollador. La copia dentro de este repositorio se conserva como respaldo,
pero la URL raíz es la que debe verificarse en AdMob.
